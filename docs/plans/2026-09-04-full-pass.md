  app's palette — no shared stylesheet, no imports.

## 7. Risks & mitigations

- **Covenant drift (no shared CSS):** bevel/cursor recipes are per-app
  implementations of one documented pattern; reviewer greps for imports/
  shared classes.
- **file:// regressions:** no fetch, no modules, `.data.js` only; smoke runs
  from file://-equivalent server each WS.
- **Audio autoplay:** WebAudio context resumes on first pointer/keydown;
  default state `sounds: true` but silent until gesture; mute persisted.
- **Tauri toolchain:** first `cargo`/CLI fetch may fail offline — WS8 is
  structured to deliver a verifiable scaffold regardless.
- **Scope size:** 8 workstreams; per-WS commits + this file = resumable at
  any boundary. If a session dies mid-WS, the WS's own commit list in git
  log shows what landed.

EsotericSuite revival, native visual rebuild, any networked feature,
